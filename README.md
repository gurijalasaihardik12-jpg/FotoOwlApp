# Foto Owl

Foto Owl is a React Native image gallery application developed using
React Native, Expo, and TypeScript.

## Features

- User Registration
- Login Authentication
- Persistent User Session
- Profile Management
- Image Gallery using Picsum Photos API
- Infinite Scroll Pagination
- Pull-to-Refresh
- Real-Time Author Search
- A-M / N-Z Author Filtering
- A-Z / Z-A Sorting
- Persistent Favorites
- Favorites Search
- Image Details Screen
- Full Screen Image Viewer
- Image Download
- Logout

## Technologies Used

- React Native
- TypeScript
- Expo
- React Navigation
- Zustand
- AsyncStorage
- Expo File System
- Expo Media Library
- Picsum Photos API
